# Proposal

## Why

Сегодня заключение о контракте принимает один движок. Для линейных условий над bigint можно независимо доказать в Lean то же утверждение либо его отрицание и обнаружить расхождение с Z3 на конкретном пути программы.

## What Changes

- При обычной верификации автоматически запускать обе проверки для поддерживаемых обязательств одного снимка исходников. Первая версия охватывает совместимость предусловий, предусловия вызовов и постусловия реализаций на линейном фрагменте bigint.
- Сохранять исходные вердикты Z3 и Lean и результат их сравнения для каждого обязательства. Конкретные входы для отчёта и регрессионных тестов предоставляет Z3.
- Различать согласие, противоположные доказанные выводы и отсутствие подтверждения. При конфликте локальный результат становится `unknown`. Недоступность Lean или предел автоматического доказательства отражаются в отчёте и сохраняют самостоятельный результат Z3.

### Modified Capabilities

- `static-verification` — область независимой проверки, полярность утверждений, локальный итог сравнения.
- `verification-diagnostics` — два исходных вердикта, их привязка к обязательству и диагностика расхождений.

## Impact

Затрагивает общее ядро программного API, CLI и Vite, JSON-отчёт и проверки потребителей отчёта. Для независимого подтверждения потребуется установленный Lean 4 согласованной версии. Установка npm-пакета и проверка Z3 остаются доступны без Lean. Совпадение относится к модели, полученной из общего внутреннего дерева TypeScript.
