# Proposal

## Why

Разработчикам нужна проверка контрактов в привычной сборке без контрактных вызовов и предикатов в production JS. Сейчас CLI проверяет исходники, но нет общего API проверенного снимка и интеграции со сборщиком.

## What Changes

- Общее ядро подготовки снимка, верификации и формирования отчёта; прежний CLI `verify` сохраняет поведение.
- Vite-плагин с явными entry points проверяемых TS-модулей, блокировкой сборки при недоказанных контрактах и удалением контрактов из проверенного снимка.
- Распознавание установленного API `ts-value-proof` наряду с относительными импортами API репозитория.
- Собираемый локально устанавливаемый пакет с JS/declarations, exports для контрактов, verifier и Vite, CLI bin; без публикации в registry.
- Документация, интеграционные проверки Vite, снимков, повторных сборок и установленного пакета.

## Capabilities

### New Capabilities

- `verified-build`: общий снимок проверки, production-интеграция Vite, удаление контрактов, ограничения и установка пакета.

### Modified Capabilities

- `source-analysis`: доверенная идентичность API установленного пакета и допустимый bare import этого API.

## Impact

Изменяются adapter/source-graph и выделяется общее ядро из CLI. Добавляются Vite-плагин, преобразование исходников и сборка пакета. Vite — optional peer и dev dependency; TypeScript, Z3 и средство source maps — runtime dependencies инструмента, не приложения. Область доказательства остаётся ограниченной текущим языком; код приложения вне выбранных графов не объявляется проверенным. Dev server продолжает обычную работу без доказательства/удаления; production и build watch проходят проверку заново.
