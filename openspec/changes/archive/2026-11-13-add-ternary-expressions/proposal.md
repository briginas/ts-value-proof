# Proposal

## Why

Тернарные выражения `?:` сейчас отклоняются, хотя эквивалентные `if/else` уже проверяются. Поддержка позволит писать обычные условные выражения без разворачивания в statements.

## What Changes

- Поддержать вложенные `?:` с boolean-условием в поддерживаемых выражениях тела и контрактов.
- Сохранить ленивый выбор ветви, зависимости результата, условия путей вызовов и проверки деления на ноль.
- Сохранить ограничения вызовов, мутаций, непрозрачных значений и числовых моделей.
- Добавить проверки, пример и обновить README и руководства.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `source-analysis`: разрешить исходный `?:`, определить места использования и ограничения.

## Impact

Адаптер TypeScript, валидация IR и анализ зависимостей; существующие solver/runtime используют уже имеющееся ветвление. Публичные API и зависимости пакета не меняются.
