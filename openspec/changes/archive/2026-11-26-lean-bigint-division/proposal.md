# Proposal

## Why

Сейчас контракт функции `quotient` из примера деления подтверждает только Z3. Независимая проверка должна учитывать и знак частного, и исключение JavaScript при делении на ноль.

## What Changes

- Расширить независимую сверку на деление двух поддерживаемых выражений bigint.
- Проверять ненулевой делитель там, где операция вычисляется, до принятия любого определённого вердикта Lean.

## Capabilities

### Modified Capabilities

- `static-verification` — деление bigint в независимой проверке контрактов.

## Impact

Транслятор обязательств Lean, интеграционные тесты, пример в README и руководства по сверке.
