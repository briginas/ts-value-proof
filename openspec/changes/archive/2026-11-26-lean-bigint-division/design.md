# Design

## Context

Транслятор обходит типизированный IR отдельно для каждого обязательства. Локальный Lean 4.19 проверяет обе полярности формулы и допускаемые аксиомы.

## Decisions

- Использовать `Int.tdiv` для точного частного со знаком. Обычный оператор Lean для целых использует евклидово деление.
- При переводе каждой операции собирать требование ненулевого делителя под текущими условиями вычисления. Предусловие проверяется до того, как его можно принять за гипотезу. Аналогичный порядок действует для условия пути вызова.
- Тело функции и используемые фактические аргументы вычисляются до выражений, которые читают их значения. Защита внутри постусловия или предиката callee не защищает это более раннее деление.
- Проверять область определения как универсальную цель в том же пакете Lean и принимать вывод о контракте только при доказанности этой цели. Внутренние цели не добавляют строк в публичный отчёт.

## Risks / Trade-offs

При сложных символических делителях возможен `unknown` в пределах действующего бюджета. При делении на ноль тотальное значение Lean не должно попадать ни в доказательство контракта, ни в опровержение.
