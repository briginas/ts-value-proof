# Proposal

## Why

Умножение пока превращает числовые обязательства в unknown. Поддержка `*` позволит проверять произведения и квадраты в существующих моделях bigint и number.

## What Changes

- Поддержать `*` в числовых выражениях, предикатах, условиях путей и аргументах вызовов.
- Сохранить точную bigint-семантику и JavaScript binary64-семантику number, включая специальные значения.
- Дополнить проверки и обновить списки операций в README и руководствах.
- Деление, остаток, возведение в степень и неявные преобразования остаются неподдерживаемыми.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `source-analysis`: распознавание числового умножения и проверка типов IR.
- `static-verification`: точное умножение bigint и binary64 с сохранением unknown при исчерпании ресурсов.

## Impact

Адаптер, IR, общий движок обязательств, оба числовых backend, тесты и документация. Новые зависимости и изменения публичного contract API не нужны.
