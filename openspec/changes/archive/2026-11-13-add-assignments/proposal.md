# Proposal

## Why

Функции с локальными `let` уже разбираются, но любое обновление значения отклоняется. Поддержка присваиваний позволит проверять обычные последовательные вычисления и накопление результата в ветвях.

## What Changes

- Поддержать отдельные statements `=`, `+=`, `-=`, `*=`, `/=` для локальных `let` и параметров; строковый `+=` сохраняет UTF-16.
- Сохранять порядок вычисления, снимки локальных значений, входные аргументы контрактов, ветвления, switch/fallthrough/break и исходные call IDs.
- Оставить неподдерживаемыми запись в свойства/элементы, destructuring, вложенные присваивания, `++/--`, остальные составные присваивания и вызовы/getters справа.
- Добавить проверки, пример и обновить ограничения в README и обоих руководствах.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `source-analysis`: присваивания значений и сохранение аргументов вызовов с учётом конкретного пути выполнения.

## Impact

Адаптер TypeScript, преобразование statements в IR, проверка целостности вызовов, тесты и документация. Публичный contract API и числовые модели не меняются; новых зависимостей нет.
